# Development roadmap

## Phase 1 — Foundation and public website shell
- Set up Next.js, TypeScript and Tailwind
- Create school branding and design system
- Build responsive header, footer and public layout
- Implement homepage with hero and pillar sections
- Add basic reusable components

## Phase 2 — School information pages
- About Soneike page
- Academics page
- Sport overview page
- Discipline page
- Culture & Leadership page
- Contact page

## Phase 3 — Content and community features
- News listing and article detail pages
- Events calendar and filtering
- Clubs and societies overview
- YCAP and community projects page
- HESOP content page
- Achievements showcase

## Phase 4 — Sports management foundation
- Sports codes and team model
- Fixtures and results management
- Coaches and players/learner participation records
- League tables and tournament announcements
- Sports achievements

## Phase 5 — Admin dashboard and secure CMS
- Secure login and role-based access
- News management dashboard
- Event management dashboard
- Sports dashboard for fixtures and results
- Image uploads and media manager
- Staff and achievement management

## Phase 6 — Final polish and launch readiness
- SEO optimisation
- Accessibility audit
- Performance and image optimisation
- Security review
- Deployment configuration
- Content migration and launch prep

## Future roadmap beyond launch
- Parent and learner portals
- Attendance and behaviour modules
- Academic performance tracking
- Admissions and communications workflows
- School operations dashboards
